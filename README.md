📈 6. WORKFLOW
A. Content Planning
1. Weekly planning meeting (Content Director + Team) if necessary.
2. Define content goals: awareness, engagement, conversion, etc.
3. AI tool proposes content variations (viaOPEN SOURCE )
4. Calendar is updated in Trello or Notion
B. Production & Editing
1. Scripts are written by humans or co-generated with AI 24/7
2. Video recorded live or in studio TM. 
3. AI tools (Runway, Descript) used for editing, captions, voiceovers
4. Final content is approved by the Compliance Officer (reviews)
C. Platform-Specific Preparation
Platform	Guidelines
Facebook/Instagram	Respect Meta's guidelines: no hate speech, graphic violence, or misinformation. Use Reels and Stories for engagement.
YouTube	Follow monetization and copyright rules. Use thumbnails, tags, chapters. Age-restrict where needed.
X (Twitter)	Be aware of real-time interaction, trending content. (Avoid spamming or violating ad transparency.)
TikTok	Vertical-first, community-driven. Watch out for music licensing and sensitive content flags.
LinkedIn	Professional tone, industry updates. No NSFW or personal drama content.
D. Publishing & Distribution
1. Use centralized tool (e.g., Restream, Hootsuite) for synchronized publishing
2. Include captions, ALT text for accessibility if necessary 
3. Optimize for platform specs (aspect ratio, duration, file size) constant development for the platform and user base.
4. Include Surreal Live TV branding watermark
E. Post-Publication Monitoring
1. AI moderation tools monitor for policy flags or takedowns
2. Human reviews analytics within 24 hours of post
3. Comments moderated for toxic language (via AI first, human backup)
4. Audience engagement metrics tracked

🤖 8. AI USAGE POLICY
* AI is a co-creator, not a replacement for humans.
* AI-generated content must be clearly labeled (when relevant).
* No use of deepfakes or impersonation tools without (express permission).
* AI used for:
    * Captioning and translations
    * Summarization and script drafts
    * Thumbnail and banner image design
    * Comment moderation and analytics

📺 9. LIVE BROADCAST PROTOCOL (TELEVISUAL COMMUNICATION)

2. 5-minute countdown with branded animation. Time zones
